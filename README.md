Data Cleaning & Reporting Automation

This project uses Power BI to clean and analyze employee data. Missing values were handled, duplicate records were removed, and inconsistent entries were standardized. Interactive visualizations, including employee count, average salary by department, department distribution, and KPI metrics, were created to provide clear insights and support efficient reporting.
